# Rehman Ali 👋

### Computational Ultrasound Imaging · Inverse Problems · Medical Imaging

I develop **physics-based computational methods for quantitative medical ultrasound imaging**, with a focus on wave propagation, inverse problems, ultrasound tomography, sound-speed estimation, aberration correction, and full-waveform inversion.

My research combines **wave physics, computational imaging, numerical optimization, and high-performance scientific computing** to develop reproducible methods for quantitative ultrasound.

## 📚 Selected Research Software

### 🌊 Wave-Equation Migration Velocity Analysis

**[WEMVA](https://github.com/rehmanali1994/WEMVA)**
JAX implementation of wave-equation migration velocity analysis for medical pulse-echo ultrasound.

WEMVA adapts wave-equation migration velocity analysis to ultrasound for **sound-speed estimation and aberration correction**, providing open-source implementations and experimental datasets for reproducible research.

---

### 🔄 Full-Waveform Inversion for Ultrasound Tomography

**[WaveformInversionUST](https://github.com/rehmanali1994/WaveformInversionUST)**
Frequency-domain full-waveform inversion for ultrasound tomography using a ring-array transducer.

---

### 🧮 Full-Waveform Inversion for USCT

**[FullWaveformInversionUSCT](https://github.com/rehmanali1994/FullWaveformInversionUSCT)**
Full-waveform inversion for transmission ultrasound computed tomography using the angular spectrum method.

---

### 🧊 3-D Full-Waveform Inversion

**[3D-FWI-MultiRowRingArrayUST](https://github.com/rehmanali1994/3D-FWI-MultiRowRingArrayUST)**
Three-dimensional full-waveform inversion for multi-row ring-array ultrasound tomography using k-Wave simulations.

---

### 📡 Fourier Beamforming

**[FastFourierBeamformers](https://github.com/rehmanali1994/FastFourierBeamformers)**
Open-source implementations of fast Fourier-domain beamforming methods for pulse-echo ultrasound imaging.

---

### 🌀 Curvilinear Ultrasound Imaging

**[CurvilinearAngularSpectrumMethod](https://github.com/rehmanali1994/CurvilinearAngularSpectrumMethod)**
Angular-spectrum and Fourier beamforming methods for curvilinear ultrasound arrays, with MATLAB and Python implementations and example datasets.
